# Journal Reflection

Use `journal_search` when the user asks about their entries, experiences, moods, habits, or personal timeline.

1. Search using the user's meaning, not only exact words.
2. Distinguish direct entry evidence from interpretation.
3. Mention dates or entry titles when they help establish a pattern.
4. Treat missing results as insufficient journal evidence.
5. Do not supplement private-journal questions with public web search unless the user explicitly asks for comparison with external information.
6. Keep private details scoped to the current user.
